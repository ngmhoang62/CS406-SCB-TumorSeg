# Các vòng thực nghiệm trước

Thư mục này lưu script, notebook, cấu hình, test và báo cáo từ các tuần trước khi chuyển sang baseline toàn ảnh.

README.original.md ghi cấu trúc và kết quả tại commit a65b31e. Các tài liệu ở đây mô tả hợp đồng VOI ba kênh, ResUNet, FiLM và CEHS của thời điểm đó.

Entry point đang dùng nằm ở scripts/run_pipeline.py tại gốc repo. Các import và đường dẫn tương đối trong tài liệu cũ thuộc cấu trúc trước khi gom vào legacy. Git history tại a65b31e giữ đầy đủ source tương ứng để tái lập các kết quả lịch sử.
